# Document research

Read and follow **`.cursor/skills/document-research/SKILL.md`** end to end.

## North star

Persist the **full thought process** so future agents do not duplicate experiments, do not reopen rejected scope, and can assemble README + report from files alone.

## Steps

1. Read [`docs/research/PROJECT_KNOWLEDGE.md`](../../docs/research/PROJECT_KNOWLEDGE.md) and [`DECISIONS.md`](../../docs/research/DECISIONS.md).
2. **Scope** — question, filename, decisions to log, experiments to reference.
3. **Gather** — local PDFs, STATUS, JSON/analysis cards, code.
4. **Draft** — investigation note per `reference.md` (include reasoning chain, rejected/deferred, experiments table).
5. **DECISIONS** — append row for every accept/reject/defer.
6. **Index** — README, PROJECT_KNOWLEDGE, LITERATURE_HIGHLIGHTS; STATUS closeout if arm finished.

Do not commit unless asked.
