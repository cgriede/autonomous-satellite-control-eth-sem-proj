\subsection{Limitations}
\begin{itemize}
  \item \textbf{Model fidelity:} spherical Earth, 2D attitude kernel, simplified cloud primitives.
  \item \textbf{Control interface:} direct torque learning is an interim experimental stack, not the target hierarchical mission planner.
  \item \textbf{Generalization:} results hold for the documented mission randomization ranges only.
\end{itemize}
